Sobre Mim

Sou formada em Análise e Desenvolvimento de Sistemas pela Uninter e em Gastronomia pela PUCRS, com trajetória marcada por uma transição sólida para a área de tecnologia. Atuo com foco em desenvolvimento Front-end, suporte técnico e automação de processos, unindo organização, pensamento analítico e experiência prática em ambientes reais de TI.

Durante minha experiência como estagiária de Suporte em TI, realizei atendimento a usuários, acompanhamento e resolução de demandas técnicas, além do desenvolvimento de scripts em Python e Bash voltados à automação e otimização de processos internos. Também participei da criação de dashboards e interfaces analíticas utilizando Python, Jekyll e bibliotecas como Dash e Pandas para coleta, análise e visualização de dados.

Possuo experiência no desenvolvimento de interfaces web responsivas com HTML, CSS, JavaScript e Bootstrap, além do uso de Git e GitHub para versionamento de código. Utilizo Figma e Canva para planejamento visual e criação de interfaces e materiais digitais, sempre buscando equilibrar usabilidade, clareza e estética.

Busco oportunidades como Desenvolvedora Júnior ou Suporte em TI, onde eu possa continuar evoluindo tecnicamente e contribuir com soluções eficientes e bem estruturadas.

Projetos em Destaque

Painel de Demandas Interativo

Aplicação web desenvolvida com Python e Dash para monitoramento e visualização de demandas a partir de issues do GitHub. O sistema utiliza gráficos interativos, filtros dinâmicos e integração com a API do GitHub para análise de dados e acompanhamento das demandas ao longo do tempo.

Relógio Digital Inteligente — PWA

Aplicação web interativa de relógio digital utilizando HTML, CSS e JavaScript puro, estruturada como uma Progressive Web App (PWA) instalável. O projeto inclui personalização de tema e cores, modo foco em tela cheia, persistência de preferências com LocalStorage e integração com API de clima baseada em geolocalização. A aplicação foi construída com foco em experiência do usuário, performance e manipulação avançada do DOM sem uso de frameworks.

Gerenciador Financeiro + Manual Educacional

Aplicação web desenvolvida com HTML, CSS e JavaScript que integra aprendizado e prática financeira em um único ambiente. O projeto combina um manual interativo de educação financeira com um gerenciador de gastos capaz de registrar, organizar e filtrar despesas por período. A aplicação utiliza manipulação dinâmica do DOM e armazenamento local para simular o funcionamento de sistemas reais de controle financeiro, priorizando usabilidade, organização de dados e experiência do usuário.
